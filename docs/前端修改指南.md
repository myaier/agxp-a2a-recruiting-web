# 前端修改指南 — 想改哪里，改哪个文件

> 写给要动这个前端的人（包括让 Claude Code 代改）。原则：**每类东西只有一个该去的文件**，
> 找对文件，改动就不会散。

## 0. 最省事的提意见方式：标注模式（不用描述位置，不用打字）

线上或本地打开原型，**点右下角半透明 ✎**进入标注模式，然后：

1. **点任何看不顺眼的元素** → 弹出输入条（手机上可点键盘麦克风**语音听写**）；
2. 说一句想怎么改，「记下这条」；逛到别的页接着点、接着记；
3. 攒够一批 → 点 ✎ 上方的**数字角标** → 「复制全部」→ 整段贴给 Claude。

每条标注自动带页面路由 + 元素在源码里的位置（形如 `在谈首页-module__薪资`，
即 `src/屏幕/在谈首页.module.css` 的 `.薪资`），Claude 拿到就能精确改，
你全程不用解释「在哪个页面哪个位置」。意见存在浏览器本地，刷新不丢；「清空」可重来。

零成本替代：**截图**直接拖进 Claude Code 对话框（Cmd+Ctrl+Shift+4 框选，Claude 认得出是哪屏）；
打字累就用 **macOS 听写**（连按两下 fn）。

## 1. 起本地环境

```bash
cd ~/agxp-a2a-recruiting-web
npm install        # 只需第一次
npm run dev
```

浏览器开 `http://localhost:5173`。**保存文件即热更新**，不用刷新。

- 浏览器窗口开宽 → 桌面机身模式（一台 iPhone）
- 窗口缩窄到手机宽度（或手机访问局域网地址）→ 全屏 App 模式
- 想直达某屏调试：地址栏改哈希，如 `http://localhost:5173/#/app`（主壳）、`#/deal/neg_01` 需按路径表（见 `src/路由/路径表.ts`）

## 2. 「我想改 X」速查表

| 想改什么 | 去哪个文件 | 举例 |
|---|---|---|
| 卡片里的公司 / 职位 / 薪资 / 对话内容等**演示数据** | `src/数据/模拟数据.ts` | 把「云衢科技」换成别家、加第 6 张在谈卡、改今日简报数字 |
| **颜色 / 圆角 / 阶段配色 / 顶部渐变** | `src/样式/设计令牌.css` | 换品牌绿、调卡片圆角 —— 改一处全局生效 |
| **某一屏的布局 / 间距 / 字号** | `src/屏幕/<屏名>.tsx` + 同名 `.module.css` | 屏名↔设计稿编号对照表见 [README](../README.md#屏幕对照表) |
| 跨屏复用的**按钮 / 卡片壳 / 返回栏 / 输入条 / 开关** | `src/组件/通用.tsx` + `通用.module.css` | 改主按钮高度 → 所有屏的主按钮一起变 |
| **底部三 Tab 玻璃导航** | `src/组件/玻璃导航栏.tsx` | 加第四个 Tab、换图标 |
| **桌面机身框**（灵动岛 / 状态栏 / 缩放） | `src/组件/设备外框.tsx` | 换机型尺寸、去掉机身 |
| **图标** | `src/组件/图标.tsx` | 全是内联 SVG，新图标照着已有的加一个导出 |
| **跨屏联动逻辑**（决策→阶段推进→规则出现） | `src/状态/应用状态.tsx` | 加新的全局动作 |
| **页面跳转关系 / URL** | `src/路由/路径表.ts` + `src/应用.tsx` | ⚠️ 路由参数名必须 ASCII（`:id`），中文参数会让路由失效 |
| 手机浏览器行为（允许浏览器缩放 / 全屏 / 标题） | `index.html` | — |

## 3. 加一个新屏（三步）

1. 在 `src/屏幕/` 建 `新屏.tsx`（+ 需要的话 `新屏.module.css`），照任一现有屏的写法；
2. `src/路由/路径表.ts` 加一行路径；
3. `src/应用.tsx` 挂一行 `<Route>`。

从别的屏跳过来：`const { 跳转 } = use导航();` 然后 `跳转(路径.新屏)`。

在仓库目录里开 `claude`，直接说人话即可，但带上这两样效率最高：

## 5. 改完之后

```bash
npm run typecheck
```

零输出 = 通过。然后提交源码 + 发布线上，两步是分开的：

```bash
git add -A && git commit -m "改了什么" && git push
```

```bash
npm run deploy
```

`deploy` 会构建并强推 `gh-pages` 分支，约 1 分钟后
https://myaier.github.io/agxp-a2a-recruiting-web/ 生效（浏览器缓存顽固时强刷）。

## 6. 常见坑

| 现象 | 原因 / 解法 |
|---|---|
| 页面白屏 | 看终端里 vite 报错；多半是 TS 类型错，`npm run typecheck` 定位 |
| 改了颜色没生效 | 颜色都要走 `var(--xxx)`；直接写十六进制的话下次改令牌不会跟着变 |
| 布局莫名横排 | CSS 的 flex 默认横向；竖排容器要显式 `flex-direction: column` |
| module.css 里动画不动 | `@keyframes` 必须定义在**同一个** module.css 里（CSS Modules 会改名） |
| 发布了线上没变 | 确认跑的是 `npm run deploy`（`git push` 只传源码不发布）；再强刷 |
| 路由点不进去 | 路由参数名用了非 ASCII，见 §2 表格最后一行的坑 |
| 安全区写死 env() | 一律用 `var(--安全区上/下)`，否则桌面机身模式会错位 |

## 7. 接后端时

对照 [`docs/后端接口需求.md`](后端接口需求.md)：在 `src/数据/接口层.ts` 里实现一个
`HTTP数据源`（fetch + 字段映射），把最后一行 `export const 数据 = 模拟数据源` 换掉即可，
所有屏幕代码零改动。演示数据全部集中在 `src/数据/模拟数据.ts`，届时整文件可删。
