# 公司主页资料编辑页规格（用户 2026-08-20 截图，BOSS「编辑品牌信息」对标）

入口：招聘名片页 →「公司主页资料」行。

用户原话：「参考我的截图来设计一下，就是用户点开之后和我的截图里的内容是一样的，用户可以编辑」。
→ **内容项一比一照搬截图**，视觉用我们自己的风格（荧光绿/墨、极简，不抄 BOSS 配色）。

## 页面结构（从上到下）

1. **顶栏**：返回 ‹ ＋ 右侧「预览」（点开看候选人视角的公司主页 = 现有 企业详情 屏）。
   截图右上还有「邀请同事来编辑」——本原型无多人协作，不做。
2. **大标题**：编辑品牌信息
3. **完善度卡**：环形百分比 + 档位词（一般/良好/优秀）+「完善 N 项信息，提升公司主页曝光率」+「去完善」按钮（点了滚动到第一个未填分区）。
   百分比 = 已填项 / 全部项，实时算，不是写死。
4. **分区清单**（每行：标题 + 计数 或 「去添加 ›」；有计数的可折叠展开子项）：

| 分区 | 计数 | 子项 / 编辑内容 |
|---|---|---|
| 基本信息 | N/6 | 公司全称、公司 LOGO、行业、规模、融资阶段、办公地址 |
| 公司福利 | N/2 | 福利标签（多选 chips）、作息（双休/大小周/弹性） |
| 公司介绍 | 去添加 | 多行文本 |
| 主营业务 | 去添加 | 多行文本 |
| 公司相册 | N/3 | 实景照片、公司照片、公司视频（原型：图片上传占位，视频只做占位行） |
| 人才发展 | 去添加 | 多行文本（培养机制、晋升通道） |
| 在职感受 | 去添加 | 多行文本 |
| 产品介绍 | 去添加 | 多行文本 |
| 高管介绍 | 去添加 | 列表：姓名 + 职务 + 一句话简介（可增删） |

## 交互

- 每个分区点开 → 底部升起编辑层（或次级页），改完保存回列表，计数与完善度即时更新。
- 已填的分区行右侧显示摘要（如公司介绍显示前 12 字 …），未填显示「去添加」。
- 全部数据落全局并持久化（localStorage 键 `AGXP公司档案v1`），候选人侧 企业详情 屏读同一份。

## 2026-08-20 用户标注后的调整（以本节为准，覆盖上文）

1. **分区编辑不做底部升起层，改成独立页面**：`/hr/company-profile/:area`
   （段用 ASCII slug：basic / welfare / intro / business / album / product / team）。
   版式：返回栏（左 ‹ + 右上「保存」）+ 大标题（分区名）+ 全屏编辑区；
   长文分区用整屏 textarea，字数计在右下角。保存后返回清单；直接返回 = 丢弃改动。
2. **删掉分区**：人才发展、在职感受（连同覆盖字段一并清掉；候选端原有的在职感受统计
   `感受项[]` 是平台侧数据，保持不动）。
3. **高管介绍 → 团队介绍**（字段名 `团队介绍`、类型 `团队成员项`），结构不变。
4. **删掉完善度卡**（环形百分比 / 档位词 / 「完善 N 项信息…」/「去完善」）与整套完善度逻辑。
   分区行右侧的 N/6、N/2、N/3 是分区自己的计数，保留。
5. **删掉顶栏右上的「预览」**，返回栏只留左侧 ‹。

调整后的分区：基本信息 N/6 · 公司福利 N/2 · 公司介绍 · 主营业务 · 公司相册 N/3 · 产品介绍 · 团队介绍。
