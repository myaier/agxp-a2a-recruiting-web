## 三、Issues（非阻塞）

1. **[环境噪音，非本次改动] 走查期间多次整页 reload 丢失 onboarding 进度。** console 出现多轮 `[vite] connecting...` 重连（Browser pane 后台 tab 被回收 + 同源多 tab 并存所致），reload 后内存态丢失、路由弹回 #/identity，且 #/student 选择回落默认「在校学生」。产品层面事实：onboarding 中途状态不持久化（简历「保存」之后才写 localStorage）。真实用户中途刷新会从头再来，是否可接受建议产品确认。
2. **[低] 基本信息身份与到岗题默认值不联动。** 基本信息选「离职」后，引导问答到岗题默认仍选中「在职·考虑机会」，用户需手动改为「离职·随时到岗」。建议按基本信息身份预选对应档位。
3. **[说明] 年份滚轮在本走查环境无法用鼠标拖拽/滚轮驱动**（触摸目标交互；drag/scroll 手势均无响应）。已用编程滚动验证吸附与选中逻辑正常（滚至 2019 高亮、完成后回填、经验重算正确），真机触摸预期可用；建议在触摸模拟或真机补一次手势复核。
4. **[低·UX 观察] 从 #/resume 点行进入基本信息编辑，「下一步」落到 #/experience（onboarding 编辑链）而非返回简历页。** 与学生路径行为一致（存量行为），非回归；是否改为「保存返回」由产品定。

## 四、走查中排除的误报

- 一度观察到 `简历v2.基本信息` 存成 `{身份:"在校", 在读学历:"硕士在读"}`——复盘为前一轮被 reload 打断后误走学生分支的污染数据；清空重走非学生干净链路后落库正确，**非 bug**。
