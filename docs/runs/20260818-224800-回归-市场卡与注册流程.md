## 过程问题记录（均非应用缺陷，供后续测试参考）

1. **dev server 整页重载风暴**：并行开发会话的 HMR 编辑 + 构建导致 8083 页面每 ~40-70s 整页 reload（`performance.navigation.type=reload`），React 内存态（抽屉开合、tab 选择）反复丢失。对策：切到快照静态构建测试。曾观察到一次陈旧 HMR 模块报错「图标.tsx 不提供导出 相机图标」（`t=1787061791482` 旧时间戳缓存），当前源码该导出存在，非缺陷。
2. **vite 8 preview 不可用作测试底座**：`vite preview` 对带 `Sec-Fetch-Dest: script` 头的模块请求返回 404（curl 无此头则 200，逐头二分定位），浏览器加载 JS 必带此头 → 白屏。另 sirv 启动时快照 dist 文件清单，dist 被并行会话重建（hash 变名）后旧清单 404。对策：python http.server + 符号链接模拟 `/agxp-a2a-recruiting-web/` base 前缀。
3. **断言时序**：React 18 下 `btn.click()` 后同一宏任务内查 DOM 偶发拿到旧树，统一在每次点击后 `await 150-400ms` 再断言；受控 input 需原生 value setter + `dispatchEvent(new Event('input',{bubbles:true}))`；`常用条件` 备选片文本带「＋ 」前缀，精确匹配需含前缀。
4. **构建 base 前缀**：生产构建 `base=/agxp-a2a-recruiting-web/`（GitHub Pages），本地静态服务需同名子路径。
