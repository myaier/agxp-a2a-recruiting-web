# 2026-08-20 求职者注册流按 BOSS 截图顺序重排

## 目标流程（学生路径）

登录 → 选身份 → 引导说明(/intro) → ①完善资料(/student) → ②期望月薪(/wizard 首题)
→ ③创建在线简历(/basic) → ④求职状态(/onboard/status) → ⑤最高学历(/onboard/degree)
→ ⑥你毕业于(/onboard/school) → ⑦你的专业是(/onboard/major) → ⑧就读时间段(/onboard/eduyears)
→ ⑨向导续答（硬性排除 → 个人优势）→ 披露说明(/disclosure) → ⑩添加头像(/onboard/avatar) → 主壳(/app)

非学生路径：⑧ 之后先进 工作经历(/experience)（保存键原有跳 /wizard 逻辑不动）再回向导续答。

## 每屏数据落点

| 屏 | 采集 → 落点 |
|---|---|
| 完善资料 /student | 是学生 → `基本信息.身份`（点击即落，选是清 `开始工作年`）；上传简历 → `简历文件名`；快捷职位 → `引导预填.职位` |
| 选工作城市 /onboard/city | 多选城市（≤10）→ `引导预填.城市们` |

| 期望月薪 /wizard 首题 | → `引导预填.薪资`（`存薪资预填`，答完跳 /basic，回向导跳过），逻辑未动 |
| 创建在线简历 /basic | 你的姓名 → `基本信息.真名`；性别 → `基本信息.性别`；出生年月 → `基本信息.出生年/出生月`；非学生 开始工作年份 → `基本信息.开始工作年` |

| 最高学历 /onboard/degree | → `简历教育[0].学历` |
| 你毕业于 /onboard/school | → `简历教育[0].学校` |
| 你的专业是 /onboard/major | → `简历教育[0].专业` |
| 就读时间段 /onboard/eduyears | → `简历教育[0].开始/结束`（'YYYY-09'/'YYYY-06'） |
| 向导续答 /wizard | 题序 = 硬性排除 → 个人优势（职位/城市/薪资按预填跳过、到岗题已删）；答案仍仅屏内 useState（原状） |
