## 过程中发现并修掉的问题

1. **scroll anchoring（滚动锚定，内容增高时浏览器自动补偿 scrollTop）与平滑滚动打架**：
   卡在视口上方展开时锚定补偿会取消 `scrollIntoView` 动画。
   修法：谈判进度滚动区 `overflowAnchor: 'none'`。
2. **内嵌预览环境冻结 smooth 动画（后台渲染 rAF 节流）**：滚动改在 effect 里派发
   （等展开正文提交 DOM 后），并加 400ms 兜底 —— 位置纹丝不动就瞬移到位。
   真实前台环境仍是平滑滚动。
3. **Rules of Hooks**：滚动 effect 最初写在 `if (!单)` 提前 return 之后，已全部移到 return 前。
4. **切单状态残留**：`/deal/J-01 → /deal/J-02` 同路由只换参数、组件不重挂载，
   展开状态会带到下一单。加了按 `编号` 重置为收起的 effect。
