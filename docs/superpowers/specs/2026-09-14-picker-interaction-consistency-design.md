# 城市、行业、薪资选择与就读年份交互统一

日期：2026-09-14。版本：v1.1。

状态：设计方向已获用户同意；本文待用户审阅批准，尚未进入实施 Plan 或产品实现。

## 1. 目标与边界

解决用户在真实使用中发现的行业不能收起、行业弹层不能滚动、年份看似已选却无法继续三个缺陷，同时统一岗位城市与月薪的选择体验。所有本轮改动同时作用于 Mock 与 Backend，不能只做 Backend 专用页面。

本轮前端调查基线：`5825ff47a27600cbe5591fb1a9a5fe43e7201272`。遵守 `CLAUDE.md`、`AGENTS.md`。后端只作接口核对，不在本轮修改；执行环境按当地配置定位后端仓库，不依赖规划机器路径。

用户已同意“局部统一”：行业保留各自的全页/弹层外壳；岗位城市采用全页选择；月薪采用双滚轮；空就读年份明确显示未选择；删除行业伪推荐。用户随后明确要求核实并保证 Mock / Backend 设计统一。

用户补充：Mock 数据部分保留演示预填。本设计不清空默认 Mock 演示数据；预填由模拟数据或其适配层提供，共用控件消费传入值，不能因为统一设计让默认演示变成空表单。

在本文列出的区域内，本设计覆盖以下历史约束中冲突的部分：

- `docs/design/添加求职期望规格.md` 中行业推荐区取前三个一级行业的规定。
- `docs/superpowers/specs/2026-09-12-core-editors-shared-ui-and-wiring-design.md` 中保留行业推荐区、Mock 自填、原岗位城市控件的边界，以及只保持原组件外观的限制。
- `docs/superpowers/plans/2026-09-05-frontend-only-data-pollution-deep-links.md` 中用 2021/2025 作为可见年份落点、Mock 空年份直接保存的方案。

不扩展上述历史任务的其他范围，不复制整篇旧设计或恢复退役入口。

## 3. 方案选择与工程取舍

采用“修缺陷 + 具体选择能力复用”，一份 Spec、一份后续 Plan。

- 只修缺陷虽更小，但没有覆盖用户同意的城市/月薪交互统一。
- 全站重做选择器会牵动学校、专业、公司等无关流程，当前没有依据。
- 本方案复用既有页面视觉、目录查询、弹层和滚轮，新增共享部分仅服务已存在的城市和行业消费者。删除重复列表与无意义推荐，避免多套实现继续分叉。

允许的共用边界为行业列表及其展开控制、城市选择视图及其本地选择控制；调用页面继续拥有业务草稿和持久化动作。不得把页面业务派发、角色判断、后端 DTO、所有目录种类放进万能表单或通用树框架。具体文件名、接口签名和消费者清单在获批后的 Plan 冻结。

## 4. Mock / Backend 统一合同

1. 同一业务入口在两种模式中必须调用同一个展示组件，使用同一布局、CSS、标签、控件与选择规则。不得新增 `Backend城市页面` 等平行 JSX，也不得仅共用 CSS。
2. 展示层不读取数据源模式、Context 或 raw BFF DTO。查询和保存适配层允许分别使用真实接口与模拟数据；展示输入以稳定键、文字、状态和回调表达。
3. 相同目录形态、已选项和状态，产生相同布局与可操作结果；不同数据量、真实定位缺失、网络失败等通过共同的状态表达，不要求虚构数据使内容逐字相同。
4. Mock 行业使用既有行业字典的父/子结构和局部稳定模拟键，父项只展开，细分项可选。删除工作经历 Mock 独有的自由行业输入。模拟键不发送给后端。
5. 保留默认 Mock 演示会话的已有预填数据及可直接继续的体验，包括现有就读年份 2021/2025。若这些演示值当前仅写在页面兜底中，将其移至现有 Mock 数据或适配层，由它向共用页面提供完整有效年份，不新增全局预填机制。只有明确的空数据场景（例如空值测试 fixture、用户清除后的字段）才与 Backend 一样显示未选择、不可保存；不得在控件内部把空值自动补回演示数据。Backend 不消费这些模拟默认值。
6. 岗位城市、月薪的新版交互同时替换两模式。原有效表单数据和角色权限继续由页面负责。
7. 新增或调整测试必须覆盖两模式同输入/同交互，不以“Backend 测过”替代 Mock 验收；Mock 不产生真实 API 写入，Backend 失败不回退 Mock。

## 5. 行业选择

### 5.1 页面行为

删除期望行业的“推荐”标题和前三个大类 chips，不用随机细分项或硬编码列表补成新推荐。保留已选数量、分类列表和保存入口。

两处行业使用同一份可折叠列表：父行有明确展开/收起状态；细分项可选；保留已有层级缩进与标签视觉。期望行业保持全页、最多 3 项、选择即更新意向草稿，顶部保存/返回仍只返回；本轮不改造成新的取消事务。工作经历保持底部弹层、单选，选定后立即回填当前经历草稿并关闭，尚未选定时关闭不改行业。

选择只按 `selectable`，展开只按 `has_children`，不能按名称、层级或是否是根节点猜测。若节点同时可选且有子项，行内选择区与展开按钮分别承担两个动作，点击展开不改变选择；正常不可选父项只显示展开动作。模拟数据遵守相同规则。

### 5.2 展开、缓存与请求

可见展开状态与已加载子项缓存分离。重复点击父行切换展开/收起，收起只隐藏后代，不删除已选细分项；重新展开可复用当前目录版本的已加载结果，不重复发同一加载请求。

支持多个大类同时展开。收起父项后，后代可见展开状态一并收起；重新展开先展示直接子项，缓存仍可复用。加载中的节点可收起，迟到响应可完成同版本缓存，但不能自动把节点再次展开。重复展开不得并发重复请求。

保留现有根/子/孙三级及分页能力；超出当前三级的不可选节点不伪装成可选叶子，显示无法继续选择的明确状态，留待真实目录需求另行扩展，不在本轮引入无限树。目录版本变化作废旧缓存/游标/在飞响应；版本变化不静默修改已选业务值，后续保存的合法性仍由现有接口验证。

分页、空结果、加载失败采用共同状态；失败可重试，不能缓存成成功空表。已选按 ID 去重，同名不同 ID 不串。多选达到上限只禁止新增选项，不阻止展开、收起或取消已选。

### 5.3 弹层布局与焦点

恢复简历行业面板的 72% 最大高度，使标题/抓手留在面板内，行业列表拥有单一内部滚动区。多根展开、分页追加、短屏和手机横屏下，首尾选项与关闭方式仍可达。

修正底部 `弹层框架` 覆盖调用方高度的行为；保留居中确认框定位。检查受影响消费者的最大高度与滚动，不能一处恢复另一处裁断。局部重渲染/展开不得反复将焦点抢回首项；首开聚焦、Tab 边界、Escape、关闭后焦点恢复保留。只修这个已触达的生命周期问题，不重写弹层系统。

## 6. 岗位城市采用全页选择

复用现有全页工作城市的搜索、默认目录、分组、已选项和保存布局；标题为“选择工作城市”，不显示多选计数。岗位新建时点击城市行打开，编辑已发布岗位仍按现有不可变规则锁定。

全页是当前岗位表单内的本地子视图，不新增业务路由或全局岗位草稿仓库。岗位表单实例、当前步骤、其他字段和 JD 导入运行态保持挂载；选择视图打开时原表单不可交互、不可被键盘或读屏误访问。顶栏返回及 Escape 关闭子视图；浏览器后退沿现有岗位页面路由离开行为，不制造新的隐藏历史项。刷新不新增岗位草稿持久化，沿原页面生命周期。

选择视图持有本次临时值，单选，可取消当前选中项；空选择不能点保存。保存原子回填城市显示名和目录引用后返回原步骤；关闭不回填，原岗位其他字段保持。不得把招聘者导航到候选专属 `/onboard/city`，不得写入意向草稿、引导预填或求职者权限域。

Backend 只接受实际目录项或岗位当前合法引用，不按名称推测 ID；Mock 从本地城市数据选择。搜索、默认目录页使用既有查询能力，不预载整个目录。搜索失败不能伪装成“没有匹配的城市”，在共同视图显示错误与重试；无结果与失败分开。重新搜索、关闭/重开、切换主体后，迟到响应不得写回旧选择或岗位。

JD 城市源文本保持为待用户核对的提示/搜索初词，不能自动成为城市引用；没有引用仍阻止发布。用户在选择页操作期间到达的 JD 结果不得覆盖当前临时选择；保存后以用户选定引用为准。候选引导的 10 城多选、意向主城市单选维持原业务；备选城市 0/9 页面本轮不重做。

## 7. 岗位月薪双滚轮

社招全职与校园招聘的月薪主入口改为显示薪资区间的选择行，打开既有 `薪资区间层` 的双滚轮；两模式同改。日薪/时薪及年薪月数保持各自现有控件，不重排其页面。

弹层内修改只影响临时值；“确定”回填上下限，“取消”/Escape/遮罩关闭保持原值。空岗位薪资仍显示未填写；弹层可以有 10/11 K 的可见初始档位，但只有显式确定才进入岗位草稿。用户主动确认与自动默认写入严格区分。

复用常用月薪档位，并将当前有效上下限加入可选档，保证打开后原样确定不会夹值或取整。岗位现有输入/映射为非负整数，不在本轮扩展岗位小数协议；求职意向既有小数/大额值的往返能力不得回归。

岗位常用滚轮以 0–100 K、步长 1 提供选择，弹层内保留“输入金额”作为次级入口，使用原数字框的整数输入规则覆盖此前可填写的 0–9999 K。服务端已有且可由现有映射处理的超范围整数随当前值补入档位，不因 UI 限制被截断；不为宽范围创建上万 DOM 档位。已有求职端默认档位与显示文案不因岗位接入而改变。

上下限倒置时，岗位“确定”显示字段错误并保持弹层，不静默调高/交换。该行为延续岗位原校验；求职端现有确定时上限取 max 的行为保留，通过显式业务策略传入，不根据 Mock/Backend 分叉。数值完整合法才回填，最终提交仍使用现有薪资映射和后端校验，不改变单位或金额倍率。

## 8. 就读年份的可见空态

入学年、毕业年使用可空的有效选择状态。值可来自已有资料、可用解析建议，或 Mock 数据层显式提供的演示预填。默认 Mock 演示继续显示已有的 2021/2025，并允许直接下一步；不清空 Mock 样例。页面实际收到空值时，两列明确显示“请选择”，没有任何数字项高亮选中；相同空输入在两模式中行为一致。不再用显示 2021/2025 + 隐藏确认标志的双状态方案。

保留页面现有 2000–2030 年档和有效预填规则。未选择时滚轮显示一个“请选择”的空项；用户点击任意年份、键盘选档或真实滚动到年份即选中，不要求先换到其他年份再滚回来。程序定位/挂载不视为用户选择。已有值、有效建议或 Mock 显式预填正常预选，直接下一步可用；数据层传入的越界/缺失保持未选，不在控件里使用当前年份兜底。

点下一步时，缺失项附近出现持续可见的错误，修正对应项后清除；起止倒置仍由现有起止年月校验拒绝，不提交简历。两项有效才拼接既有入学 9 月、毕业 6 月并保存。学生预计毕业年份可在现有范围内选未来年；不改 end_month 为 null 的其他页面合同，不改 onboarding 题序。

保留真实预填 eligibility、已确认分区、保存成功后确认分区和跳转时序；用户选择即时更新现有建档草稿，返回/刷新在已有草稿能力内恢复。滚轮的可空能力只服务这个现有需求，其余出生年月、薪资、数字、年月消费者继续使用既有非空行为，不顺便改出生年月收集规则。

## 9. 状态与外部接口

- 行业：仍读取 `GET /api/v1/catalog/industries`；用户选择持有稳定引用，持久化沿现有意向/简历接口。
- 城市：仍读取 `GET /api/v1/catalog/locations`；岗位继续提交 `location_id`，意向继续提交各自城市引用。
- 岗位：仍使用原 POST/PATCH，保留 sparse patch、revision/If-Match、结构化要求确认、组织坐标和失败恢复逻辑。
- 岗位名称 title 与职位类别 category_id 仍分开；类别预填名称、用户改名后不覆盖、发布后不可变保持。
- 不新增后端接口、请求框架、全局持久化、配置开关、推荐服务或虚拟列表基础设施。

## 10. 验证与完成标准

复用现有 Vitest、Playwright 和类型检查；后续 Plan 写明具体变更文件、定向命令、最小消费者集合和预期断言，不新增测试平台。单元测试不能代替真实浏览器高度/滚动验证。

| 边界 | 必须证明的结果 |
| --- | --- |
| 两模式一致性 | 同业务入口使用同一展示；同输入下标签、选择、禁用、折叠、错误一致；默认 Mock 演示预填保留，空 fixture 单独覆盖；Mock 零真实写入 |
| 行业 | 两处 × 两模式；删除推荐/Mock 自填；单选与 3 项上限；收起后已选不丢；重复展开/收起、在飞收起、失败重试、分页换版、同名 ID |
| 实际布局 | 行业展开两个大类和大量子项后，面板受限且列表可滚动到首尾；短屏可关闭；重新渲染不抢焦点；其他底部弹层和居中确认框不回归 |
| 城市 | 岗位全页保存/取消，已填 JD/薪资/企业等不丢；不写候选草稿；错误与无结果分离；同名城市按 ID；JD 文本不可直接提交 |
| 薪资 | 新建/编辑 × 社招/校招 × 两模式；0、9999、现有超常用档金额往返；取消零变化、倒置报错；求职端已有小数和大额值原样；无金额倍率变化 |
| 就读时间 | 默认 Mock 显式预填 2021/2025 可直接继续；两模式空值/单侧值/已有值/解析建议/越界建议；空态无数字 selected；直接点击目标年成功；用户清空后不重新注入演示默认；空值和倒置零提交；刷新草稿及确认分区时序 |

定向测试通过后按实际 diff 检查共享消费者，执行所需类型、lint、构建和浏览器回归，不为纯规划先重复全量测试。真实后端行为验收使用 `docs/dogfood/真实后端行为验收.md`，具体环境、账户、范围及清理在实施 final gate 方案中列出并获批；fixture 浏览器测试不标成真实后端通过。缺前置准确记录未完成责任，不扩大成全部 Hosted 场景。

最终成功标准是用户能够按可见状态完成选择和保存，且 Mock/Backend 的相同业务入口具有相同设计；不能只以所有旧测试通过宣告完成。

## 11. 非目标与延后项
