# 底部抽屉组件统一 Implementation Plan

> **For agentic workers:** Claude Code 必须使用 `superpowers:subagent-driven-development`；Codex 必须使用 `superpowers:executing-plans`。依下列 Task 顺序执行，收尾不计数；本文件不授权规划 session 实施。

**Goal:** 所有现存薪资、日期、年份和实习数值编辑入口使用对应共用底部抽屉，且打开时背景不跳动。

**Architecture:** 扩展现有薪资、年月、数字组件，调用页拥有业务状态和持久化；增加一个承载现有年区间的薄抽屉，不复制滚轮。仅修复公共弹层的聚焦滚动，保留当前项目视觉与业务差异。

**Tech Stack:** 现有 React 19、TypeScript、CSS Modules、Vitest、Playwright；沿 package-lock.json，不升级依赖。

**Spec:** `docs/superpowers/specs/2026-09-15-bottom-drawer-unification-design.md`，批准内容 revision `0e07383dad5e5288ef641a96e5d673bbcceb577f`，blob `bf3c8383f6dac7147060360111296bd8c5d0ffcb`。随后 Spec 仅记录批准状态，不以未批准新内容替代该契约。

版本：v1.1。状态：已完成 Claude 文档 review 及两项 required finding 的核实修订，无未解决有效 required；尚未实施。

## Global Constraints

- 用户明确要求最小实现，样式遵循当前项目样式。沿现有选择行、顶栏、字体、间距、圆角、遮罩和滑入动画；不设计新主题、不重排无关字段、不引入新依赖。
- 相同字段使用同一实际控件与 JSX；不是仅共用 CSS/hook。Mock 与 Backend 同入口同展示，组件不读数据源模式、Context 或 API。
- 页面显示父值/未填写；打开建立临时值；顶栏“取消 / 字段标题 / 确定”；取消、遮罩、Escape、卸载不回填；确定完整回填一次。页面继续拥有原业务保存/失败恢复职责。
- 薪资范围、算法、校验时机、金额单位/倍率、日期精度、预填资格及空值合同全部按批准 Spec §6 保留。
- 不新增后端/API/schema、全局弹层管理器、通用表单、路由/history、持久化服务、配置开关或虚拟列表。
- 全屏目录改造由另一个 session 负责；公司选择形式不变。对重叠文件只改抽屉区域及必要 import、状态和测试，不拥有整页。
- 遵守 `CLAUDE.md`、`AGENTS.md`。同一执行者完成 Task、实施 peer review、affected、final gate 和合入；不创建第二用户工作区、不 stash/reset/clean 他人内容。
- 每个 Task 先写会暴露真实错误的测试、确认失败原因，再做最小修改。文档 review 不运行测试；实施回归不删弱旧业务断言来换取通过。

## 文件与接口总图

- `弹层框架`：焦点生命周期；保留现有 props，不新增容器体系。
- `数字滚轮层`：单个数值的连续/离散档，增加可选离散属性，旧范围 API 兼容。
- `年月滚轮层`：一个 YYYY-MM，增加年份档与可访问名，保留原上下界算法。
- 新 `年份区间层`：两个 number|null 临时值，使用既有 `内嵌双滚轮`，唯一业务消费者为 onboarding 就读时间段。
- `薪资区间层`：所有薪资入口统一 JSX；用 `用途` 扩展表达现有引导策略；新 `引导薪资档位.ts` 仅迁移现有纯数据/算法，组件不依赖页面。
- `内嵌双滚轮`：增加可选零值文案与右列空位、独立可空列值适配能力仅在现有联合类型内使用；保留原两分支值类型，不新增通用渲染插件。
- `e2e/抽屉稳定性.spec.ts`：逐帧背景稳定、事务和现有样式截图附件；随各 Task 增加用例，使用现有 Playwright config。

**Interfaces：** 在原 props 增加下述判别联合；既有 `标题/初值/单位/确认/取消` 保持。非空数字档由调用方静态提供，禁止范围与离散混传：

```ts
type 档位输入 =
  | { 档位: readonly number[]; 最小?: never; 最大?: never; 步长?: never }
  | { 档位?: undefined; 最小: number; 最大: number; 步长?: number };
// 初值:number；确认:(值:number)=>void；取消:()=>void，其余既有属性保持。
```

离散初值在表中则原样选中；不在表中取最近档、距离相同时取较小档；调用方的缺值临时传首档，父字段仍是未填写。连续范围沿原吸附，不修改工资日/时薪的旧基线算法。确定键统一“确定”。
