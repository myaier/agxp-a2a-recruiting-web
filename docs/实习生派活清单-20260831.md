### 2. 公司档案补缺(P0 · 1 天)
- M-13 美团是新增岗,`公司档案` 无 meituan 条目,点「所属公司」可能落空;顺带盘点 市场列表/在谈列表 出现过的全部公司(MiniMax/阶跃星辰/商汤/蚂蚁/PingCAP/京东…),缺档案的补齐(名称/首字/规模行/介绍段/融资阶段/行业/成立/地址)。
- 验收:每个出现过的公司,从职位详情点进公司页都有完整资料,无兜底空页。

### 3. 漏斗埋点层(P0 · 3 天)
- 现在零埋点。做一个轻量事件上报模块(先落 localStorage + console,后端就绪后换上报),覆盖:注册完成、发布岗位、委托代理(让AI代理去谈)、进入在谈详情、确认意向、开始私聊。
- 验收:每个事件带时间戳与匿名会话号;有一页隐藏调试面板能看到事件流水;单测覆盖事件去重。

### 4. 招聘端全流程 e2e(P1 · 3 天)
- 现有 e2e 偏求职端。补:注册→发岗→初始化页→候选推荐→候选详情(代谈进度/在线简历)→停止招聘确认框,全程真实入口、断言真实输出(见 `~/.claude-config/rules/ui-e2e-testing.md` 的 e2e 定义,mock 掉核心模块不算 e2e)。
- 验收:新 spec 并入 `npx playwright test` 全绿;含关闭职位居中弹窗断言。

### 5. 种子数据清理:非 AI 岗残留(P1 · 1 天)
- 市场列表/推荐列表里仍有与产品定位不符的岗位与画像,按现有 AI/后端画像统一;顺带核对每个岗的 `技能要求` 是否与其 JD 文本一致(匹配分析条目=JD 硬性要求)。
- 验收:逐岗对照表(岗位 → 技能要求 → JD 原句出处)附在 PR 描述里。

### 6. 无框审计(P1 · 2 天)
- 全站原则「所有设计不要框」。逐页截图盘点仍带卡壳/描边框的页面(设置族已改),产出清单:页面 → 截图 → 是否该去框 → 工作量。**只出清单不动手**,改动逐页经老板效果图确认。
- 验收:一份带截图的审计文档。

### 7. 「职位描述重复」bug 复现(P1 · 1 天)
- 老板在真机见过发岗后职位描述出现两遍,本地/线上/编辑态均未复现。任务:多机型/多入口穷举复现路径(含 iOS Safari 缓存、编辑后返回再进),复现即记录步骤,修复另立任务。
- 验收:复现步骤文档,或给出「无法复现 + 排除清单」。

### 8. 简历 PDF 上传解析预研(P2 · 3 天)
- 现在简历数据是结构化种子。预研:浏览器端 PDF 文本抽取(pdf.js)→ 结构化(段落→经历/教育/技能)的可行性 demo,不进主干。
- 验收:一个独立 demo 页 + 三份真实简历的抽取效果对比文档。

### 9. docs/INDEX.md 与 DEV_LOG 建档(P2 · 1 天)

- 验收:INDEX 覆盖 docs/ 全部文件;DEV_LOG 每条含日期与一句话理由。
